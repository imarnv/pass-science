Formulation

−d/dx ( kA dT/dx ) = qA,  0 < x < L

Ke = (kA/h) [ 1 −1 ; −1 1 ],  fe = (qAh/2) [ 1 ; 1 ]

Texact(x) = T₀ + (TL−T₀)x/L + (q/2k) x(L−x)

  • Steady state, constant k, A and q; lateral surface insulated
  • Both end temperatures prescribed (Dirichlet), imposed by eliminating the two boundary rows and moving their known contributions to the load vector
  • SI units: m, m², W/(m·K), W/m³, °C (only temperature differences enter K)

What the numbers show

Nodal values are exact to round-off for every mesh: in 1-D, linear elements with a consistent load vector reproduce the exact solution at the nodes. A nodes-only comparison would therefore report zero error and hide the discretisation error.

Between nodes the FE field is linear while the exact field is quadratic, so the error peaks at each midpoint at exactly q h²/(8k). Halving h divides it by four — an observed order of 2.

Method

  • Timed region: solving and storing results only. Case generation, file I/O, rendering and compilation are excluded.
  • Parallel path: a fixed pool of p std::thread workers pulls chunks of 4 cases from a bounded queue; each case writes only its own result slot, so output order is deterministic.
  • T₁ is the one-worker pool run (same code path as Tₚ); the serial loop is listed for reference.
  • Each solve is memory-bound (Thomas algorithm, O(N)), so speedup is limited by memory bandwidth and allocation, not only by core count.

Recovery policy

Connect is retried up to 3 times with a 250 ms timeout and exponential back-off starting at 50 ms.

  • Timeout once — the next request fails; an automatic retry recovers.
  • Unplug — every request times out; retries are exhausted and the device shows faulted until the fault is cleared and the user reconnects.
  • A telemetry timeout marks the device faulted; Recover reconnects it.
